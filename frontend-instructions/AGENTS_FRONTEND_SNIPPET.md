## Frontend instructions

Before changing anything under `resources/js/` or `resources/css/`, read
`frontend-instructions/FRONTEND_INSTRUCTIONS.md` and the guides it routes to
for the task. `docs/DESIGN.md` is the binding visual specification; the pack
defines engineering patterns, component usage, forms, lists, and verification.
Do not edit generated Wayfinder files under `resources/js/routes`, `actions`,
or `wayfinder`; do not reformat `components/ui` primitives. For an explicit
unslop/polish request, also read the `unslop` skill; `docs/DESIGN.md` still
wins on tokens and composition.

Project-specific visual spec and profile paths live in
`frontend-instructions/PROJECT-PROFILE.md`. Replace that file and
`PROJECT-SURFACES.md` when copying the pack into another Laravel + Inertia +
React project.
